# Seminar 01: Metrics and Distances

This seminar covers:
- **Distances between distributions**.  
- Common metrics to measure the quality of generative models:
  - *Inception Score (IS)*  
  - *Fréchet Inception Distance (FID)*  
- How to build or adapt a metric for a custom task.

Two main notebooks are provided:

1. **`distances.ipynb`**: Introduction to *KL divergence*, *JS divergence*, and practical experiments comparing them.  
2. **`metrics.ipynb`**: Explores *Inception Score (IS)*, *FID*, and demonstrates *LPIPS* (a learned perceptual metric) for image comparison.
